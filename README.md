<h1>🎮 Guess My Number!</h1>

<p>Guess My Number is a simple and interactive number-guessing game built with HTML, CSS, and JavaScript. The goal is to guess the secret number between 1 and 20 using the fewest attempts possible.</p>

<p>The game provides hints to help you determine whether your guess is too high or too low. Your score decreases with each incorrect guess, while your high score is saved so you can try to beat your previous best.</p>

<h2>✨ Features</h2>
<ul>
  <li>🎯 Random secret number between 1 and 20</li>
  <li>💡 Higher/lower hints</li>
  <li>🏆 Score and high-score system</li>
  <li>🔄 New game with the Again! button</li>
  <li>📱 Responsive design for mobile and desktop</li>
  <li>🎨 Modern dark-themed UI</li>
  <li>⚡ Built with HTML, CSS, and JavaScript</li>
</ul>
